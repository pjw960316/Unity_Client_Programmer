# 코딩테스트
- 너무 큰 수의 경우 특정한 수로 나누어 답을 추출하도록 한다.
- 이 때 연산 과정에서 부터 모듈러를 이용할 수 있다.

# 용어
- Modulo = % = 나머지 연산
- Reminder = r = 나머지 = 잉여 값
  
# 모듈러 세계에서 같은 수
![image](https://user-images.githubusercontent.com/55792986/196369873-a7d5c627-caf0-41f6-a798-dbb1715923a6.png)
- 예를 들어, C가 10이라고 가정하자.
  - 이 세계에서 10과 같거나 큰 수는 존재하지 않는다.
  - 즉 **1과 11은 같고, 1과 21은 완전히 같은 수다.**
- :star:완전히 같다는 개념을 명확하게 이해하지 않았기 때문에 코딩테스트에서 의심이 생겨 틀리는 경우가 있었다.

# 나열
### 1. 짝수 / 홀수
- 짝수는 %2 == 0
- 홀수는 %2 == 1

### 2. 수를 세가지로 나눠야 한다면?
- 나머지가 0인 수 -> %3 == 0
- 나머지가 1인 수 -> %3 == 1
- 나머지가 2인 수 -> %3 == 2
