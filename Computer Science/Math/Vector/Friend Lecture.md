# Class Vector3
- 본질은 벡터는 점이다.
- 3D에서 방향
- 자유도 = 공간을 정의하는데 필요한 최소한의 숫자의 개수
  - degree of freedom , dimension
- 방향을 정하는 방법이 두 점을 고르는 것
  - (0,1,0)과 (0,2,0) -> normalization
- 3D에서 normalization을 통해 하나의 자유도를 제거하니까 2D가 되는거다.
- 3D의 방향을 고른다는 것은 구면의 점 하나 찍는 거랑 같다.

- normalization을 해야 방향을 나타낸다.
  - 케이틀린 궁을 쓴다.
  - 케이틀린의 위치와 상대의 위치와 투사체 속도.
  - 상대위치와 케이틀린의 차는 벡터다. 
  - 이걸 normalization하면 크기가 1이면 방향

# :star:결론 : 벡터는 방향(normalize)과 크기(scalar)를 구분해서 생각한다.
- 방향은 항상 normalization을 한 크기 1 벡터
- 크기는 스칼라 값으로 저장할 수 있다.

# Normalize
- :star:노멀 벡터는 방향!
- 방향만 아는 벡터지만 이걸 취했을 때 수학적인 계산이 많이 간단해진다.
- 계산은 어차피 컴퓨터가 하니까 상관없지만, 개발자의 가독성 증가
  
# 내적을 할 때 두 직선의 각도를 구할 수 있다.
- 이 때도 normalize를 한다.
- 두 직선이 이루는 각도 공식은 정말 반드시 알아놔야 한다.

# 벡터 두 개만 알 때 수선의 발을 내렸을 때 거리
- a의 normalize 벡터와 b의 normalize 벡터를 내적하면 a벡터에서 내린 수선의 발의 길이다.
- 이건 직접 손으로 나중에 계산해본다.
