### 5. 고민
- Previous Unity Study 시리즈에는 오류가 많다.
  - 유니티를 처음 공부할 때 작성한 문서라 더 알고나면 오류가 보인다.
  - 캡처나 출처를 남기지 않은 것은 믿을 수 없다.
- 지금이야 출처도 남기고 캡처도 더 많이 하고 마크다운이라 수정이 용이하지만, 당시에는 HWP -> PDF로 변경한 것이고 PDF는 유료기 때문에 해당 문서를 수정하기 매우 불편하다.
- 해결방법 : PDF를 구매하거나 MARKDOWN으로 완벽히 마이그레이션을 하거나.
  - 부분 마이그레이션은 계속 진행중.
