  - 간단한 사용법과 이론은 구글링 하면 나온다. 단지 구글링 시간을 줄이기 위한 문서가 되면 안 된다.
  - **간단한 내용으로 양을 채운 지식은 머릿속에 남지 않더라.**
  - 당시에 공부했던 LinqPad7코드를 반드시 추가하고, 쓸모 없는 지식이 보이면 바로 제거한다.
