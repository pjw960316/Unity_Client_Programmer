# 공부 계기
- 나는 대학 때 해당 강의를 수강하지 않았다.
  - 아마 2학년 과목이었고 당시에는 언어와 핵심CS가 중요하다고 생각해서 수강하지 않았다.
  - 동기들의 수업 후기를 들으면 좋은 판단이었다고 한다.
    - 도움이 되지 않았다는 평이 많았다.
- 실무를 경험해 보고 느낀 것이 이 내용을 암기할 필요는 없다. 하지만 큰 흐름은 알고 있어야 될 것 같다.
  - 소프트웨어 공학에 대한 저명한 설계 방식을 공부하는 것은 정도를 걷는 길이 아닐까?
  - :star:**이걸 암기하는 것은 필요도 없고 불가능 하지만 이런 설계가 있다는 기억을 통해 찾아 볼 수 있는 능력이 필요할 것 같다.**

# 학습 목표
- 시니어들이 말했던 용어가 생각보다 책에 많다. 이들을 공부한다.
- 누가 봐도 시니어나 프로젝트 매니저가 결정하고 수행할 내용이라면 공부하지 않는다.
- 신기한 기술들은 재미 삼아 읽어보자.

# 시니어와 주니어
- 시니어는 프로젝트 설계를 주도적으로 하기 때문에 그들이 더 알아야 할 것 같다.
- 하지만 시니어와 일을 하는 주니어가 최소한 시니어의 명령을 수행하려면 간단하게는 알아야 할 것 이다.
