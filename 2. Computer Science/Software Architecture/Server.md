# 개요
- 클라이언트 개발자지만 서버개발자와 소통을 해야 하므로 서버에 대한 기본적인 정보는 알아야 한다.
- 서버 개발자의 딥한 내용까지는 지금 공부할 필요는 없지만 가볍게 알면 좋을 것 같다.

# 얄팍한 코딩사전
- 서버도 컴퓨터다. 서버는 역할의 개념이다.
  - 여러 컴퓨터 사이에서 중개해야 하므로 성능이 좋아야 할 것 이다.
  - 서버는 클라이언트 컴퓨터의 시다바리다.
- 예시
  - 한 컴퓨터가 톡을 보내면 다른 컴퓨터에 해당 톡을 전달해주는 컴퓨터가 서버다.
  - 여러 클라이언트 컴퓨터가 하나의 게임에 참여할 수 있도록 해주는 컴퓨터가 서버다.
- 서버들은 IDC(=Internet Data Center)라는 시설에 밀집해있다.
