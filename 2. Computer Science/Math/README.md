# 개요
- 수학의 부족함을 느꼈고 친구의 조언도 달게 받았다.
- 좋은 게임 개발자로 성장하기 위해 수학을 공부한다.
- C++ 코드도 함께 적어가며 수행한다.

# 생각
- 게임 개발, 코딩테스트, 게임 플레이에서 모두 기초 수학이 부족해서 어렵게 만드는 경험이 점점 증가하고 있다.
  - 특정 라이브러리 함수를 이해하기 위해서는 해당 수학적 개념의 이해가 필요하다.
  - 코딩테스트에서는 모듈러 연산, 기하학, 확률 관련 개념이 문제 속에 녹아있는 경우가 증가한다.
  - 게임은 특히 순열과 조합 및 수식 계산이 중요하다.
- 기초 CS지식이 나의 개발 실력을 밑에서 지탱하고 있을 것 이다. 그 중 가장 약한 부분이 기초 수학이라고 생각한다.
- 대학 때 충실하지 못한 점이 이제 조금 느껴진다.
    
# 조언
- 수학적 개념을 코드로 구현하는 방법을 연습하기 이전에 개념을 이해하고 :star:수학 문제를 손으로 직접 풀어봐라.
  - 개념이 많이 부족하지는 않을 것 이다.
  - 수능 및 모의고사 3점, 4점 수준의 연습문제를 풀어봐라.
- 수학 관련 코딩테스트 풀 시간에 수학 개념을 공부하고 연습문제를 푼다.

# 코딩테스트와 수학
- 수학관련 문제가 어려웠던 이유는 이런 생각이 들어서다.
  - 코드로 어떻게 방정식을 만들지? , 이런 수식은 코드로 어떻게 구현하지?
  - 하지만 이건 틀렸다.
- *star***코딩테스트의 수학 문제를 푸는 것은 일반 수학 문제를 푸는 방식과 동일하고 계산만 컴퓨터가 해주는 것** 이다.
  - 수식 방정식은 모두 종이 노트에서 해결한다.
  - 해당 방정식을 풀기 위한 계산을 코드로 구현하고 계산을 컴퓨터에게 맡긴다.
    - math.h의 cos,sin,tan,sqrt,pow가 이를 도와준다.
