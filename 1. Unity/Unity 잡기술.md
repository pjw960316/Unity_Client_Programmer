# 계층이 빡센 GameObject에서 원하는 부분 찾기
- Scene에서 거기를 더블클릭하면 Hierarchy에서 알아서 찾아간다.
- 물론 버튼 같은 거여서 이중으로 겹쳐있으면 올바르게 찾아가지 않을 수 있지만 그래도 근처까지는 간다.

# Auto Refresh를 끄자.
- **장점**
  - 이 기능을 키면 코드를 조금만 변경해도 빌드를 하여 최신화 시켜준다.
    - 매 번 Ctrl + R로 빌드를 해 줄 필요가 없다.
- **단점**
  - 조금만 변경해도 빌드를 하기 때문에 시간 낭비가 심하다.
    - 빌드는 시간이 많이 소요된다!
  - 빌드를 까먹으면 변경 되지 않는다.
    - 까먹고 변경 되지 않았다고 착각하는 순간 정신 나간다.
    - 디버깅 포인트가 붉게 나오지 않은 것으로 해결할 수 있다.
      - 코드와 유니티에서 latest 빌드한 내용과 다른 부분은 디버깅이 되지 않는다.
