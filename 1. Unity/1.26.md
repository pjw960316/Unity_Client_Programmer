# unity auto refresh
- 이거를 끄면 지 맘대로 빌드는 안 하는데 내가 빌드를 해줘야 함 ctrl + r로
  - 만약 빌드 안하면 디버깅 포인트를 비교해보면 디버깅 포인트가 안 찍힌다.
  - 왜? 빌드를 안 해서 코드랑 유니티에서 인식한 거랑 다르니까

# 메서드
- 함수는 최소한 2번 이상 사용될 때 가치가 있다.
- 얘는 죽어도 1번만 쓸 것 같으면 굳이 뺄 필요 없다. 재상용이 안되 니까
