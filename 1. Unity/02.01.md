# Action Func
~~~c#
private void ActionFunc()
    {
        Action<int, int> a = (x,y) =>
        {
            Debug.Log($"{x}  {y}");
        };

        Func<int, int, int> b = (x, y) =>
        {
            var z = x + y;
            return z;
        };
    }
~~~
    - action의 generic은 매개변수만
    - func의 generic은 매개변수와 리턴 값 같이
      - 1번int와 2번 int는 매개변수, 3번 int는 리턴 값의 int를 담당
