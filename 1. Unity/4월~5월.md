# 복잡한 람다도 개념을 알고 있으면 가독성이 떨어져도 이해가 가능하다.
- 기본 함수 
  - 인자 -> 함수 구조
  - ex : Test(a)
- 람다 
  - 함수 <- 인자 구조
  - ex : (x => {함수 바디}) , 그리고 이 x 매개변수를 다른 함수에서 가져온다.
