# 깊은 복사 얕은 복사
- 깊은 복사 = call by value
- 얕은 복사 = call by ref
  - 코딩테스트 하다 보면 항상 얘가 좋은 줄 알았는데 아님
  - 얕은 복사한 녀석을 바꾸려면 깊은 복사를 하는 코드를 짜야한다.
- Jiwon a = new Jiwon(); Jiwon b = new Jiwon() a = b랑 Jiwon a = b랑 똑같음.
  - 좀 더 분석하면 좋겠지만 a에서 새롭게 객체를 만들었으니 깊은 복사가 되겠지? 아니다.

# 재사용 되는 메서드를 만드는 건 너무 어렵다.
- A Script에서 재사용 할 메서드를 Z Script에 만들고 B Script에서 재사용 했다. 근데 C SCript에서 재사용을 하려고 보니까 Z Script에 뭐를 추가하거나 고쳐야 한다. 이 능력을 잘 키워야 한다.

# perforce
- pending 에서 revert unchanged file을 해버리면 내가 변경하지 않은 거를 없애 준다.
- 그러나 공백도 변경이다. 공백은 그 이전 커밋과 비교하는 걸 이용해서 직접 revert 해준다.

# 시니어와 애송이의 차이
- 시니어는 매개변수를 최소화 하려고 하고 메서드의 기능을 단순화 시키지만 애송이는 매개변수 막 넣고 메서드가 다 하게 한다.
