# Serialize & Deserialize
- 복잡한 데이터 -> Serialize -> 간단한 데이터 -> Deserialize -> 복잡한 데이터
  - 데이터를 전송하거나 저장 가능하도록 변경하고 다시 이를 역으로 변경하여 원본으로 바꾸는 일련의 과정으로 이해했다.
- 데이터를 전송하는 예시
  - ![image](https://user-images.githubusercontent.com/55792986/216907798-7ad32ab7-70d0-422f-bed9-e8313e62eb20.png)
  - 클라가 서버로 데이터를 전송하는 과정에 대해서 생각해보자.
  - **Bytes**
    - 클라가 Int, Double의 데이터를 서버로 전달할 때 Int는 4btyte에 직렬화하고, double은 8byte에 직렬화 하여 전달하고, 서버는 이를 받는다.
      - 서버에서도 int와 double에 대해 4byte와 double이 8byte로 올바르게 저장되어 있어야 하며 이게 어긋나면 직렬화가 깨진다.
      - 그러므로 클라와 서버가 같은 언어일 때 유용한 기술 이다.
  - **Json**
    - 클라가 데이터를 일단 Json으로 Serialize를 하고, 해당 Json을 서버가 받아서 Deserialize를 하여 원본 데이터로 변경한다.
      - 언어가 달라도 직렬화가 되지만 느리다.
