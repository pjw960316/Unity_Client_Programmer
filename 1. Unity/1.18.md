# atttribute
- 코드 위에 []로 표시하는 기능
- **주석은 사람이 읽고 쓰는 정보, attribute는 사람이 작성하고 컴퓨터가 읽게 하는 기능**
  - 컴퓨터에게 지시하는 것.
- 클래스나 구조체, 메서드, 프로퍼티 등에 데이터를 기록해두면 이 정보를 프로그램이 읽어서 한다.
