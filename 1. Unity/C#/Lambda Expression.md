# 클래스의 멤버 변수를 줄일 수 있다.
- 지금까지 나는 코딩테스트에서 전역변수를 쓰듯, 클래스에서 멤버 변수를 남용했다. 
  - 멤버 변수를 사용하면 클래스 내부 메서드 어디에서든 쉽게 참조할 수 있기 때문이다.
- 하지만 클래스의 멤버 변수는 scope가 넓다. 
  - scope가 넓으면 어디서든 쉽게 참조하고 변경할 수 있기 때문에 위험하다.
- :star:**람다식을 만들면 body 부분이 새로운 scope로 잡힌다. 해당 람다식 밖에서는 람다식보다 넓은 범위의 scope가 잡히므로 클래스의 멤버 변수보다는 scope가 좁고, 람다식 보다는 넓은 변수를 생성할 수 있다.**
