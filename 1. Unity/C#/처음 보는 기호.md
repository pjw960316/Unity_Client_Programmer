# 무한한 .
- 리턴이 인터페이스인 함수가 있다. 해당 함수의 결과는 인터페이스고 그 인터페이스를 이용해서 인터페이스를 상속받을 때 구현해야 하는 메서드를 호출할 수 있다.
  - 당연히 구현해야 되니까.
- ![image](https://user-images.githubusercontent.com/55792986/213439237-d4057fdb-895f-4876-8711-d08026d07e47.png)
- partial class는 결국 하나의 클래스지만 헷갈리지 않게 해당 클래스 이름.구분 하는 클래스 이름
- 이게 되는 이유
  - ![image](https://user-images.githubusercontent.com/55792986/213450597-3e19f639-975a-4335-a739-0067daa2b794.png)
    - Observable.Timer는 리턴 값이 새로운 Observable의 자식 타입 객체다. 잘 보면 new로 객체를 만든다.
  - ![image](https://user-images.githubusercontent.com/55792986/213450907-0e921589-a5a9-486e-93e2-f377514d57e1.png)
    - 두 번 타고가면 얘는 Iobservable을 상속 받고 구현하고 있다.
      - TimerObservable -> OperatorObservableBase -> Iobservable
        - OperatorObservableBase가 subscribe를 구현한다.
  - a.b.c.d.e.f. 같은 코드가 되는 이유도 다 이렇게 매번 객체를 만들어주기 때문이다.
