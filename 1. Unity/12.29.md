# 람다식의 생성
- 델리게이트 -> 익명메서드 -> 람다식
~~~c#
private delegate void MyDelegate(int _value); //델리게이트형 선언
MyDelegate value = delegate(int _value) //무명메서드 정의
{
	Console.Write(_value);
};

value(100); //델리게이트 사용
~~~
- 델리게이트에 넣어 줄 메서드에 대해서 이름이 만들기 귀찮으니 그냥 delegate를 붙여서 만든다.
  - 여기서 만든 것이 무명메서드다.
  - 이게 또 귀찮아서 람다식으로 줄였다.

# 람다식
- 이벤트 지향 프로그래밍에 적합하다.
  - 콜백 메서드를 쉽게 만들 수 있기 때문이라 생각한다.
- 메서드를 간편하게 즉흥적으로 구현해서 사용하는 것이 목적이다.
- return 도 생략이 가능하지만 가독성 측면에서는 달아주자.
- 매개변수가 1개일 때 괄호는 선택사항. 2개부터는 명시한다. 매개변수의 타입을 쓰지 않아도 컴파일러가 유추해 주지만 명시해도 괜찮다.
  - ![20221229_165215](https://user-images.githubusercontent.com/55792986/209920578-49a1ccb5-56e4-4f5c-9fd5-fbcaf0cb6a0d.png)
- 컴파일러는 람다식을 보고 Func, Action, Delegate 일 것 으로 유추한다.
~~~c#
object parse = (string s) => int.Parse(s);   // Func<string, int>
Delegate parse = (string s) => int.Parse(s); // Func<string, int>
~~~
