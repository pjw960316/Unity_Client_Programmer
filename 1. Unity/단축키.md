# Rider 단축키
- F12
  - 메서드 정의문으로 바로 이동한다.
- Shift + F12
  - 메서드의 호출 위치를 모두 보여준다. (=참조된 모든 위치를 정리해서 보여준다.)
  - :star:만약 형식이 다양하다면 형식을 select 해줘야 하므로 Shift + F12 + Enter(Select)를 해주면 어디서 호출하고 있는지 파악이 가능하다.
- Ctrl + F -> F3
  - F3을 통해 다음에 찾은 내용으로 이동한다.
- Shift + Shift
  - 전체 검색
