## :white_check_mark: 좋은 포트폴리오와 자소서란?
- 내가 누구인지를 소개하는 글.
- 포트폴리오가 본체고, 자소서는 포트폴리오로 자연스럽게 넘어가게 만드는 표지/도입부
  - 포트폴리오가 concrete class라면, 자소서는 interface다.
  - 자소서는 증명을 할 수 없지만 소개를 할 수 있고, 포트폴리오는 이를 증명할 수 있다.
