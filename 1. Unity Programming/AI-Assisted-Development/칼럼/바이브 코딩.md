## :fire: 바이브 코딩은 이미 하고 있었고, 코드 몽키가 되는 지름길이다. <br> 코드 몽키가 ai시대에도 나쁜가?는 모르겠다.
- 과거든 지금이든 “남의 코드 복붙” 자체는 본질적으로 같다.
  - 남이 구글이냐 GPT 검색 복붙이냐의 차이
- 문제는 이해 없이 복붙하면 실력이 향상되지 않은 것
  - AI는 이걸 더 쉽게 만들어서 더 위험해졌다
- 설계는 반드시 내가 해야 한다 (구조, 책임, 흐름)
  - 구현은 직접 부딪혀서 막혀보는 과정이 필요하다
  - 막혔을 때 GPT는 “답”이 아니라 “이해용 힌트”로 쓴다
  - GPT가 준 코드는 그대로 쓰지 않는다
- 반드시 내가 다시 작성하면서 내 코드로 만든다
  - “왜 이렇게 짰는지 설명 가능”하면 제대로 쓰는 것
  - 결론: GPT는 대체 도구가 아니라 성장 가속 도구로 써야 한다
- 사수가 GPT가 된 거 뿐
