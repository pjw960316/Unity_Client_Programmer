## :fire: MVP Pattern을 써라. <br> :fire: Model = Data Class <br> :fire: View = UI Class <br> :fire: Presenter = Manager Class (Data 클래스와 UI 클래스를 연결한다.) <br> 그러므로 Manager Class는 Data Class를 private field로 들고 있다.
> M stands for Model (Which is a fancy name for **Data**)

> V stands for View (which is UI elements)

> C stands for Contoller, which is the logic **binding the two.**
