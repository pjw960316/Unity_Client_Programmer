# 개요
- 상위 클래스(Base Class)는 관리하고 있는 하위 클래스가 많다.
  - 이는 코드 추가와 삭제에 대해 관리해야 할 클래스가 많다는 것을 의미하고, 사이드 이펙트 체크할 게 많음을 의미한다.
  - 예상하지 못한 사이드 이펙트가 터질 수 있기 때문에 코딩하는 것이 두렵다! 
- 하지만 경력이 쌓일 수록 상위 클래스에 구현을 하는 경우가 많아진다. 
  - 그렇기 때문에 성장을 위해서는 상위 클래스와 친해져야 한다.

<br/><br/><br/>

# 상위 클래스에 Property를 추가하는 방식 vs 상위 클래스에 Virtual로 메서드를 만들고 하위 클래스에서 Override를 하는 방식
- 고민한 이유 : Depth가 10 이상으로 상속을 받은 Derived class에 기능을 추가하기 위해 최상단 Base Class에 필드를 추가하는 게 말이 안 된다고 생각했다.
  - 결론부터 말하면 추가에 큰 문제가 없다면 추가해라.
  - 사실 Virtual로 만들어서 override 하는 경우도 Derived class 하나를 위해 Base Class에 메서드를 추가하는 것 이다.
- 결론 : 상위 클래스에 필드를 추가하는 걸 주저하지 말아라.
