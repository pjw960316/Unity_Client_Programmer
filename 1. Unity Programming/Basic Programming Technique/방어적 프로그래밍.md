# 예외처리
- 프로그래머의 실수를 예방할 수 있는가?
  - 오히려 아니다.
  - exception이 터져도 프로그램이 돌게 된다!!!
- 시간을 낭비하지 않는다?
  - exception 처리하려면 결국 코드 읽어야 한다.
- 내 함수(매개변수 0개)라면 내가 짤 때 예외처리할 필요없이 잘 짜면 된다. 하지만 어쩔 수 없이 exception이 날 수 있는 데이터가 내 함수로 매개변수로 날아올 때는 내가 컨트롤 할 수 없는 경우다.
  - 파일을 읽었을 때 파일이 갑자기 지워져서 오지 않으면? -> 어쩔 수 없지만 예외처리 해야 한다. 
  - Assert를 처리한다. 
    - 디버깅 과정에서 프로젝트의 인원이 내가 적은 메시지를 읽고 도움을 받도록 하자.

# String vs Enum
- Ex : 동,서,남,북을 받아야 하는 함수를 만든다고 가정하자. 
  - Enum에 동서남북 4개를 저장해 놓아보자.
- String은 아무런 데이터를 넣을 수 있지만 **Enum은 정의한 동서남북만 받을 수 있다.**
  - 유효성 검사가 된다.
  - 컴파일러가 개발 과정에서 잡아준다.
