# 1. 데이터를 관리하는 클래스(보통 싱글턴)는 제대로 이해하고 있어야 한다.
- 캐릭터의 정보를 저장하고 있는 클래스 A가 있다. 
- 메이플처럼 다양한 캐릭터를 만들 수 있는 게임에서 클래스 A는 내가 접속해 있는 캐릭터의 데이터를 관리하는 클래스인지 아니면 모든 캐릭터의 정보를 관리하고 있는 클래스인지 알아야 한다. 
  - 올바르게 캐릭터의 정보의 갱신을 할 수 있다.
- 패킷이 들어왔을 때 데이터를 관리하는 클래스의 어떤 데이터를 변경하는 지 파악하고 변경 흐름을 이해해야 한다.

# 2. 서버에게 패킷을 요청할 때 좀 더 클라에서 검사를 해보고 요청 드리자.
- 클라에서 충분히 처리 가능한데 서버에게 패킷을 요청하면 서버팀에 의미 없는 공수를 요청하는 것 이다.
- 조금 시간이 걸릴 것 같다고 말씀 드리고 확실하게 하는 게 맞는 것 같다.
