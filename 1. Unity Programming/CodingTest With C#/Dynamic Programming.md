## :fireworks: DP 문제 풀 때의 마음가짐
- **구현 문제는 구현에 1시간 사용하는 만큼, DP는 시간복잡도와 점화식에 1시간 쓸 수 있다.**
- **어려운 문제는 배열이 2차원 배열인 경우가 다수 존재한다.**

## :fireworks: 문제 풀이 순서
#### :one: 알고리즘이 중요한 유형이므로 보통 고정 크기가 주어진다. → 배열 사용 
#### :two: dp[1] ~ dp[5] 정도까지 노트에 직접 써본다.
#### :three: 점화식을 도출한다.
#### :four: dp 배열의 마지막 인덱스의 값이 정답이 아닌 경우가 의외로 많으니 주의한다.
- 가장 긴 부분 증가 수열
