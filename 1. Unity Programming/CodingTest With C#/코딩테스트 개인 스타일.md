## :fireworks: 변수 이름은 다음과 같이 통일한다.
- **순회**
  - idx = 인덱스
  - i, j, k = foreach
  - pair = foreach with valueTuple
  - kv = foreach with Dictionary
  - word = foreach with char

<br>

- **container**
  - List = list , HashSet = hashSet , Dictionary = dict
  - PriorityQueue = pq
  - dp Array = dp
  - 4 path Array = path 

<br>

- **순서가 있는 변수**
  - n1, n2, n3 같이 알파벳 + 숫자로 사용한다.

<br><br>

## :fire: Int32 대신 int를 사용한다. <br> :fire: Int64 대신 long을 사용한다. <br> :fire: String 대신 string을 사용한다.

<br><br>

## :fire: '값이 0이면 종료한다'는 == 0으로 검사한다.
- ≤0 으로 검사하면 예외를 찾기 어렵다.

<br><br>
        
## :fire: 변수는 캐싱을 자주하여 가독성과 안정성을 확보한다. <br> :fire: 변수 이름은 과하게 길지 않은 게 좋다.
- 타입을 한 번 더 생각하기 때문에 실수를 줄일 수 있다.
- 조건식도 bool에 저장하는 게 훨씬 가독성이 좋고 안정하다.
- 루프 내부 지역 변수는 루프 내부에서 선언한다.
    - scope가 줄고, 스택에 잡히기 때문에 최적화에도 이슈가 없다.
