## :fireworks: 나만의 패치 버전 관리 시스템
- 롤체의 시즌과 주차별 패치처럼, HabitGame의 변경 규모를 직관적으로 구분하기 위한 기준이다.
- 버전은 `Major.Minor.Patch` 형식으로 관리한다.
  - 17.2c 패치면 나에게는 17.2.3 패치가 되는 것.

<br><br>

## :fire: Major
- 롤체의 시즌이 `17 → 18`로 바뀌는 것과 같은 단계이다.
- 나의 경우 한달 주기 정도로?

```text
2.4.3 → 3.0.0
```

<br><br>

## :fire: Minor
- 한 시즌 안에서 진행하는 주차별 마일스톤과 같은 단계이다.
- 나는 큰 컨텐츠 하나를 완성하면 진행 할 생각이다. 그리고 패치노트를 길게 적는다.
- Minor를 올리면 Patch는 `0`으로 초기화한다.

```text
2.0.5 → 2.1.0
```

<br><br>

## :fire: Patch
- 가벼운 기능 추가나 버그 수정에 사용한다.
- 롤체의 `17.15b`, `17.15c`, `17.15d`처럼 같은 Minor 버전을 보완하는 단계이다.
- 알파벳 대신 세 번째 숫자를 증가시킨다. (최대 99까지!)

```text
2.1.0 → 2.1.1 → 2.1.2
```

<br><br>

## :fire: Unity PlayerSettings 기본 지식
- `PlayerSettings.bundleVersion`: 사용자에게 보이는 버전이다.
- `PlayerSettings`는 `UnityEditor`에 있는 클래스이며, 에디터 코드에서 버전 값을 읽고 쓸 수 있다.
- 변경된 값은 `C:\HabitGame\HabitGame\ProjectSettings\ProjectSettings.asset`에 저장된다.

```csharp
var currentVersion = PlayerSettings.bundleVersion;
PlayerSettings.bundleVersion = "2.0.1";
```

<br>

- `BuildVersionHelper.cs`를 정적 클래스로 만들어 버전 조회와 변경 기능을 관리한다.
- `#if UNITY_EDITOR`를 사용해 Unity Editor에서만 컴파일되도록 한다.
- Unity의 `MenuItem` Attribute를 사용하면 상단 `Build` 메뉴에서 `BuildVersionHelper`의 정적 메서드를 호출할 수 있다.

```csharp
[MenuItem("Build/Log Current Version")]
public static void LogCurrentVersion()
{
}
```
