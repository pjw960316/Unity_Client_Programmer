# 예외처리 CODEX 시킬 것

- 이전에는 내가 직접 방어 코드를 작성했지만, 명확한 기준이 없어 충분히 도움이 되지 않았다.
- 앞으로 예외처리 공부와 실제 개발 경험을 바탕으로 기준을 직접 쌓아간다.
- 나는 기능 구현에 집중하고, Codex는 주로 코드 리뷰에서 기준에 맞는 방어 코드 누락을 확인하고 보완한다.
- 무엇을 검사할지뿐 아니라, 실패하면 건너뛸지·중단할지 등 처리 방식도 내가 정한다.
- 기준이 없는 상황은 Codex가 임의로 방어 코드를 늘리지 않고, 판단할 지점을 설명한다.
