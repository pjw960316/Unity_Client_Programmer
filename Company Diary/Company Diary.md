# 2022년 6월에 배운 것
## 6월에는 2주간 회사 프로세스를 익히는 데 집중했고, 추가로 루아를 공부했다. 
- 똑똑함, **절실함, 태도**가 중요하다. 똑똑함을 변화하는 건 어렵지만 절실함과 태도를 바꾸는 건 할 수 있다. 
  - 절실하면 올바른 태도가 나온다.
- 구체적인 목표를 세우며 살아가라.
- **타인과 의견을 공유할 때 의도를 공유해야 한다.**
  - 기존에는 문서를 작성하고나 타인에게 의견을 전달할 때 의도와 목적을 적지 않은 경우가 많았다. 개선하자.
- 어려운 것 부터 공부하려 하지마라. 기본부터 충실히하고 다음 단계로 넘어가라. 순서가 중요하다.
  - 그렇다고 어려운 걸 공부하지 말라는 건 아니다.
  - 기초도 제대로 하지 못하는 사람은 반드시 실무단계에서 기초의 부족함으로 문제를 야기한다.
- 다음 단계로 넘어가는 근거
  - 타인에게 설명할 수 있는가?
  - 관련 질문을 명확하게 대답 할 수 있는가?
- 모르는 건 모른다고 말해라.
- 너무 삽질을 하고 있다면 최소한의 질문 프로세스를 만들고 사수에게 질문한다.
- 어떤 조직에 처음 들어간다면 시간이 많을 것 이다. 이때 해당 조직에서 정리한 문서들을 열심히 읽어본다.
  - 슬랙 메시지
  - 회의록
  - 기획서


# 2022년 7월에 배운 것
- Trello로 업무를 관리하고 있다.  
  - 메인 업무(적당한 기간동안 해야할 큰 업무들)와 오늘 할 업무를 체크리스트로 구현해서 관리하고 있다. 
  - 일을 리스트업 하기 때문에 업무를 관리하기 매우 용이하다.
- 지금까지의 개발은 대부분 혼자 진행했기 때문에(협업 프로젝트도 우리가 아는 의미의 협업이 아니었다.) 협업을 위한 코딩을 하지 않았다. 하지만 회사에서는 완전한 협업을 진행하고 있다.
- Code Convention은 매우 중요하다. 다른 사람과 같이 작성하는 문서기 때문이다.
- 회사에서는 주석을 다음과 같이 작성하고 있다.
- 회사에서 하는 업무는 주니어 개발자의 성장에 모든 걸 담당하지 않는다. 따라서 개인이 시간을 내어 따로 개발 공부를 해야 한다.
